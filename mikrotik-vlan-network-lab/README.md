# MikroTik VLAN Network Lab

A practical network engineering project using MikroTik RouterOS and VirtualBox.

## Project Overview

This project focuses on VLAN segmentation, IP addressing, DHCP configuration, NAT, firewall rules, and network connectivity testing.

## Technologies

- MikroTik RouterOS 7
- WinBox
- Oracle VirtualBox
- Windows 7 Virtual Machine
